# 화면별 디자인 결정

Figma 모바일 화면에 다 드러나지 않는 결정(화면 연결, 상태, 활성 조건, 예외 트리거)을 모았습니다. 화면 ID와 경로, 구현 상태는 루트 AGENTS.md의 "화면과 경로" 표를 따릅니다. 화면 문구는 Figma가 기준이고, 이 파일과 Figma가 다르면 PR에 적고 담당자와 확인합니다. 이미 코드로 구현된 규칙은 코드 위치만 적습니다.

- 로그인 후 돌아갈 화면은 `appActions.prepareLogin`으로 기억합니다.

## 예외 화면 트리거

- 마이크 권한 거부·미지원 → S02a. 카카오톡 인앱 브라우저에서는 안드로이드에서 마이크 호출이 실패한다는 보고가 있어 다른 브라우저로 여는 안내를 포함합니다.
- 위치 권한 거부·실패 → S05b
- 병원 검색 0건(반경 10km) → S05c. 넓혀 찾기는 30km입니다(`/hospitals?radius=30`).
- 공공데이터 API 실패 → S05d
- 요약지 생성 대기 → S06a. 5단계 진행을 보여 주고, 완료 신호 없이 다른 화면으로 넘어가지 않습니다. 취소하면 처음으로 갑니다.

## 화면별 규칙

### S03 · S04a 문진

- 질문과 선택지는 `src/stores/interviewQuestions.ts`가 기준입니다. S03은 7문항, S04a는 그중 연령·성별·복용약·병력·알레르기 5문항입니다.
- 건너뛰기는 없습니다. 모든 문항에 답해야 병원 안내로 갑니다. "이전 질문"은 항상 있습니다.
- S04a 상단의 "지금까지 알려주신 내용" 칩에는 "잘 모르겠어요" 답을 남기지 않습니다.

### S06 요약지

- 항목 순서는 `src/components/summary/summaryRows.ts`가 기준입니다.
- "내용이 맞아요"를 누르면 확인 상태가 됩니다. "고칠 곳이 있어요"는 항목별 자유 입력으로 고치고, 저장하면 확인 상태가 풀립니다.
- 안내된 진료과는 AI 안내 항목이라 고칠 수 없습니다.
- 요약지 아래 "환자가 말한 내용을 정리한 것이며 진단이 아닙니다."는 항상 보입니다.

### E02 응급 카드

- 항목: 주된 증상 / 시작 시점 / 나이·성별 / 복용 중인 약 / 앓고 있는 병 / 알레르기 / 현재 위치 / 보호자 연락처
- 응급 흐름은 문진을 끝까지 하지 않으므로 묻지 못한 항목은 "확인 못 했어요"로 보여 줍니다(`src/api/values.ts`). 위치 권한이 없으면 현재 위치도 같습니다.
- 보호자 연락처가 있으면 "관계 · 전화번호"와 전화 버튼, 없으면 "등록된 연락처 없음"과 등록하기 버튼을 보여 줍니다. 카드 아래 "바꾸기 · 지우기"는 등록된 경우에만 보입니다.

### E03 보호자 연락처 등록

- 관계는 배우자 / 아들 / 딸 / 가족 · 지인(`SPOUSE`, `SON`, `DAUGHTER`, `ETC`), 전화번호, [필수] 저장 동의 체크입니다. 이름은 받지 않습니다.
- 셋을 모두 채워야 저장하기가 켜지고, 꺼져 있을 때는 빠진 항목을 안내합니다.
- 저장하기와 취소는 모두 P01로 갑니다. 내용 보기는 C01(`?from=guardian`)로 갑니다.

### P01 내 정보

- 보호자 연락처 카드: 등록됨이면 "관계 · 전화번호"와 바꾸기·지우기, 미등록이면 "등록된 연락처 없음"과 등록하기입니다.
- 지우기는 인라인 확인을 거칩니다. 연락처를 지우면 보호자 저장 동의도 함께 거둡니다.
- 저장 동의 카드에는 동의 상태, 저장 항목(관계, 전화번호), 동의 내용 보기를 둡니다. 저장 위치는 단정하지 않습니다.

### C01 · C02 동의 (초안)

- 정책이 확정되기 전이므로 상단 앰버 안내("정책이 정해지기 전의 문구예요")를 유지합니다.
- C01 동의를 거두는 방법은 P01에서 연락처 지우기, C02는 기록 모두 지우기 또는 탈퇴입니다.
- C02는 처음 로그인할 때만 거칩니다. 이후 로그인은 바로 돌아갈 화면으로 갑니다.

## 실기기에서 확인할 것

- iOS 홈 화면 앱은 Safari와 저장소가 분리되어, 카카오 인증 후 Safari로 열리거나 로그인이 이어지지 않을 수 있습니다. 로그인은 팝업이 아닌 리다이렉트 방식입니다.
- 테스트 순서: 노트북 크롬 → 안드로이드 크롬 → iOS Safari → iOS 홈 화면 앱 → 카카오톡 인앱 브라우저(마이크만)
- 데스크톱 브라우저에서는 `tel:119`가 동작하지 않을 수 있습니다. 119 번호 글자는 항상 보이게 둡니다.
